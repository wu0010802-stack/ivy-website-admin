## 共同行為

- 手勢：水平位移超過 6px 且大於垂直才接手（`touch-action: pan-y`），垂直留給頁面捲動；放開時速度 > 0.3px/ms 就換頁，否則過半才換。拖曳後的 click 會被吃掉，不會誤開對話框。
- 無障礙：`role=region`＋`aria-roledescription="輪播"`，每張 `role=group`＋「1 / 3」；非當前卡 `inert`；手動換頁用 `aria-live=polite` 念「近期活動第 2 則，共 3 則：…」，自動播放不念。按鈕都 44px。
- A 的自動播放：區塊可見 60% 以上才走；按住、鍵盤焦點（`:focus-visible`）在區塊內、分頁隱藏時暫停；滑鼠停留不暫停（同分校輪播 09-22 裁定）。減少動態預設不播，可手動開。
- 減少動態：三版換頁都直接切換、無滑動。
- 點卡片只跳示意提示；正式版沿用 `NewsDialog.vue` 的 dialog。
