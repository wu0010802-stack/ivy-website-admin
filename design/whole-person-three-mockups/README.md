# 三種單段版面 mock-up

依 2026-09-17 後續回饋，將前版兩段濃縮為同一段介紹，移除六大領域清單與展開說明。所有版本共用相同正文，方便單純比較佈局。

- `index.html`：比較入口。
- `a.html`：右側大字敘事，左側固定「關於／常春藤」，圓形照片作為收尾。
- `b.html`：左側標題與正文，右側大幅照片，背景「關於常春藤」橫排。
- `c.html`：置中標題與正文，下方小幅橫景，背景「關於／常春藤」分列左右。

三版保留固定導覽、滿版淡綠背景與獨立捲動前景。沿用上一版的品牌／導覽 CSS，正文與版型樣式放在 `proposals.css`。未修改主站；行動選單以原生 details 與少量 JS 操作，正文與固定背景在停用 JS 時仍可閱讀。

文案依據：[常春藤官網 About](https://www.ivykidschool.com/about)，沿用本次會話已核對的 1997 年創校、專業保育、生活學習與能力培養；不再展開全人教育課綱。

## 驗證與畫面

- 三版各自驗證 1440×900、1280×650、768×1024、390×844、320×740，皆無水平溢出。捲動 180px 時背景大字座標保持不變，正文向上移動 180px；背景始終覆蓋導覽下方至視窗底端，沒有 JavaScript 錯誤。
- 以腳本確認每版僅有一個正文段落，內容完全一致；比較入口的三張預覽與連結正常。C 版直接以 file URL、停用 JavaScript、減少動態開啟仍可顯示。
- 主要截圖：`comparison.png`、`{a,b,c}-desktop.png`、`{a,b,c}-mobile.png`，另保留筆電、平板與小手機畫面。
- 本次以 Chromium 檢查；Safari／Firefox 尚未實機驗證。
