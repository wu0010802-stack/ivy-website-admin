# 故事性 A 批：孩子的一天與關於常春藤 — 2026-09-25（比稿，尚未定案、未接進 web/）

使用者想讓官網更有故事性，看起來更像國際雙語幼兒園，讓家長想把孩子送來。這一批（A）**只用已經有的真實資料**：舊官網的一日流程（`../day-timeline-directions/README.md`），以及入學資訊頁的內容（`content/site-fixture.json` 的 `admission`）。沒有新增照片，也沒有虛構任何事實。

預覽：在 repo 根目錄執行 `python3 -m http.server 8766 --bind 127.0.0.1`，然後開 `http://127.0.0.1:8766/design/storytelling-a-mockup-20260925/`。上方的切換列可以即時切換各版；網址參數 `?day=now|next&en=a|b|c&about=now|a|b` 可以直接開到指定版本（預設是建議組合 `next / b / b`）。

## 現在的問題

1. **雙語只有說明，沒有實例。** 「美語融入每一天」埋在「關於」那段約 330 字、沒有分段的文字中間。舊官網一日流程有 08:30 早餐美語、11:40 午餐美語，但拍立得一句都沒提。
2. **拍立得背面把問題丟回給家長。** 六張背面的回答都是「參觀時可以詢問…」，家長問了卻沒得到答案。其實入學資訊頁已經有答案，例如導師開學前來電、前三天半天、接送證、代接要提前 30 分鐘來電。
3. **故事的高潮沒寫出來。** 一日流程裡的 16:00「愛的抱抱」最能打動家長，目前沒有用上。

## A3：孩子說的話（英文）

只放在兩張真的有美語時段的卡片上：01「Good morning, Teacher!」、03「I can do it!」（配合原本的標題「我自己來！」）。都加上 `lang="en"`，字型用 Source Sans 3。

| 版 | 做法 | 評估 |
|---|---|---|
| a | 不加英文 | 對照組 |
| **b（建議）** | 標題下一行小字，葉綠色，跟標題一樣轉 −0.8° | 像孩子說的一句話，不壓在照片上，中文仍然是主角 |
| c | 放在相片左下角，和時間戳同樣的相片印字風格 | 很像底片註記，但對比度要看照片：01 印在白衣服上幾乎看不清楚（`shots/desktop-day-next-c.webp`） |

**這和現行規則衝突。** DESIGN.md 規定英文只能用在導覽副標和外部連結。要採用 b 或 c，需要業主新增一條裁定，例如「孩子說的話可以用 `lang="en"` 小字呈現，一張卡最多一句」。

## 字型檢查（fontTools 查 cmap）

- 新的 h3 標題（安心長大、好奇提問、自在開口、抱一下，明天見。）都在 LINE Seed Bold 子集內，**不缺字**。
- **「美語」「英語」不在標題字型子集裡**，所以標題刻意不寫這兩個詞；內文用系統字，不受影響。
- Source Sans 3 的品牌子集（`source-sans-3-400-brand.woff`）包含完整 ASCII，英文句子不用另外切字型。
