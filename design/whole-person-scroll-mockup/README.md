# 全人教育：滿版固定背景 mock-up

依 2026-09-17 回饋製作的獨立可捲動提案，入口為 `index.html`。本目錄未修改主站版面。

## 畫面與操作

- 保留常春藤既有導覽與品牌字排，桌面 92px、手機 78px；下方全為淡綠背景，沒有外框或露出的白色上下邊。
- 「全人／教育」兩行大字與淡綠背景固定在視窗，右側文案隨頁面捲動；手機文案使用全寬，裝飾字在後方固定。
- 兩段內容依序呈現「全人教育與六大領域」、「在日常中培養能力」。照片縮為末段圓形照片，讓前景以文字為主。
- 使用 CSS Grid 疊層與 `position:sticky`，內容保持正常文件捲動，不攔截滾輪，也不使用內層捲軸。JS 僅處理閱讀進度與行動選單，停用 JS 仍能閱讀與捲動。
- 點「繼續閱讀」前往第二段；右側按鈕連回現有主站。減少動態偏好停用平滑捲動，保留正常捲動及靜止背景。

## 文案依據

來源：[常春藤官網・關於常春藤](https://www.ivykidschool.com/about)，2026-09-17 讀取。

保留 1997 年（民國 86 年）創校、全人教育、六大領域、遊戲／閱讀／操作、保育環境與能力培養；略去重複的課綱段落、各校開校年份、比較式宣稱及原頁不一致的年數敘述。主標是依上述精神撰寫的提案文案，不是原站逐字引言。

效果參考：[Wellington College](https://www.wellingtoncollege.org.uk/) 的 Meet the Master 區塊；觀察其固定背景層與獨立捲動前景，不複製英文引文與人像素材。

## 驗證

Chromium：2048×900、1440×900、1440×680、768×1024、390×844、320×740 均無水平溢出；向下捲動 300px 時背景與大字座標不變，前景標題向上移動 300px，導覽以下背景完整覆蓋視窗。另於 1280×600 驗證停用 JavaScript、減少動態仍可正常閱讀；手機選單與 Escape 關閉通過，沒有 JavaScript 錯誤。尚未做 Safari／Firefox 實機驗證。
