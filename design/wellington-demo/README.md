# 常春藤 × Wellington 視覺方向 Demo

獨立的官網方向提案，未修改主站。以 Wellington College 的大字理念、影像敘事與整段配色作為排版參考，使用常春藤自己的文字、圖片、影片與品牌色。

## 預覽

使用專案根目錄的 HTTP server 開啟 `/design/wellington-demo/`，或直接開啟 `index.html`。頁首「對照目前首頁」可回到現有版本。

## 本次呈現

- 校園影片首頁，提供暫停，減少動態偏好預設為靜態照片。
- 淡綠底的大字理念，搭配既有陪伴情境照片。
- 三個日常故事，可點選、鍵盤切換及展開家長說明。
- 深綠五校入口、暖黃預約段落，連至既有原型路由。

本頁文案是設計提案，未新增辦學數字或人物見證。活動與照片不代表五校皆有相同安排。預約連至原有示範流程，不送出資料。

## 素材

- `assets/hero-campus.mp4`、`hero-campus-still.webp`：既有校園影片與靜態封面。
- `design/believe-directions/value-company.jpg`：既有陪伴情境照片。
- `assets/learning.webp`、`garden.webp`、`yihua-exterior.webp`：既有學習、園藝與校舍照片。
- `assets/logo.png`：既有品牌標誌。
- `lineseed-bd.woff`：由既有完整 LINE Seed TW Bold 700 原檔，依 demo 文案重新製作子集；授權資訊見 `assets/fonts/README.md`。

無額外套件或外部素材請求。
