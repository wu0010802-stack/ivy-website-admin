## 舊站內容盤點

舊站 `/常春藤入學-admission` 本身只有標題與五校電話，內容在四個子頁；有一部分是圖片或彈出視窗，已逐一取出文字。

| 舊站子頁 | 內容來源 | 新頁位置 |
|---|---|---|
| 寶貝入學流程 | 6 步驟文字；另有一張「111 學年度分班表」海報（過期，不搬） | 01 入學流程：六步時間軸 |
| 新生入園須知 | 文字＋三張圖（兩階段必備品、每週服裝） | 02 新生入園須知：二部曲卡片、必備品勾選、服裝週表、接送、註冊須知 |
| 收退費辦法 | 補助文字＋五個彈出視窗（退費細則，取自 Wix 頁面 JSON） | 03 收退費辦法：補助卡、育兒津貼、退費規定手風琴 |
| 分班表 | 一張海報圖（113–119 學年度對照＋育兒津貼） | 04 分班對照：生日查詢＋本學年／下學年出生區間表（依今天日期自動推算學年度） |

分班規則：民國 Y/9/2～Y+1/9/1 出生為同一屆，Y+3 學年度讀幼幼班，逐年升班，Y+7 上小一；已用舊海報的每一格核對。

## 上線前要園方確認

1. 訂位金 5,000 元是否仍是現行金額，五校是否一致。
2. 補助金額（大班 15,000／學期、中小幼班 5,000／學期、特殊家庭 3,000／月、育兒津貼 5,000／6,000／7,000）是否為最新政策。
3. 每週服裝（一四制服、二五運動服、三便服）五校是否相同。
4. 「接送證（使用一個月）」的意思：是只在開學第一個月用，還是每月換發。
5. 退費規定是否仍依現行「高雄市教保服務機構收退費辦法」。
