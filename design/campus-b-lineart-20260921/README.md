# B 左右分景：建築線稿三種擺法

2026-09-21 使用者選定上一輪的 **B 左右分景**，接續要求探索建築線稿位置。本輪只比較 B1／B2／B3，正式首頁尚未套入這三款中的任何一款。

1. **B1 左欄底景**：聯絡資訊下方、切校索引上方的淡線稿橫景。照片保持原本的滿高配置，桌機與手機各自留出線稿空間。
2. **B2 校名標記**：完整線稿縮小放在校名上方，與地區、校名及聯絡資訊組成同一欄。
3. **B3 照片下緣圖帶**：照片下方獨立米白帶，放完整線稿及校名；手機放在照片與聯絡資料之間。

比較頁：`http://127.0.0.1:8781/design/campus-b-lineart-20260921/`。
獨立預覽：`stage.html?direction=b&art=1`、`art=2`、`art=3`。
伺服器若未啟動，在 repo 根目錄執行 `python3 -m http.server 8781 --bind 127.0.0.1`。

共用上一輪 `campus-fullscreen-20260921` 的 B 版型、五校資料及捲動程式；本資料夾僅新增線稿放法、比較頁與截圖。圖片直接沿用 `assets/campus-line-art-{key}.webp`，未改圖、未生成新建築，使用 CSS 與米白底融合。線稿隨 `.scene.is-current` 和照片／校名切換，空 `alt`、`aria-hidden`、不接收點擊。減少動態時五校線稿皆可見；強制色彩模式隱藏裝飾。

照片、電話、地址地圖、社群與預約暫停狀態均沿用前輪快照；缺 LINE 維持待補。這三種位置尚未定案，不影響正式 `web/` 與凍結的根目錄原型。
