沿用前輪取得的 modern-web-guidance `individual-transform-properties` 指引，以獨立裝飾層 transform 保持文字及版面不動。新增頁面標題採系統中文字型，活動卡沿用現有 LINE Seed 子集及 PingFang 後備。
