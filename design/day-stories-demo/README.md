# 孩子的一天：生活故事 Demo

獨立視覺提案，以六個生活片刻串接「孩子視角故事 → 教育重點 → 家長問題」。

## 預覽

從專案根目錄執行 `python3 -m http.server 8879 --bind 127.0.0.1`，開啟：

http://127.0.0.1:8879/design/day-stories-demo/

也可直接開啟本目錄 `index.html`（建議 HTTP 預覽）。沒有後端、表單送出或對外追蹤。

## 素材與文案

短片與縮圖取自園方既有素材 `常春藤廣告+配音.mp4`。下表時間為原始影片秒數：

| 片刻 | 原始區段 | 示範範圍 |
| --- | --- | --- |
| 早安入園 | 35.5–37.3 | 成人與孩子陪伴互動；不代表實際入園紀錄 |
| 好奇探索 | 37.5–39.4 | 老師陪伴孩子操作幾何教具 |
| 一起用餐 | 16.5–18.6 | 拿取湯匙、面紙與整理餐碗；並非實際進食 |
| 安靜片刻 | 無 | 午休分鏡示意，實拍待補 |
| 午後玩耍 | 29.9–31.55 | 戶外活動；不代表實際拍攝於午後 |
| 帶故事回家 | 19.0–23.3 | 整理書包與拉網袋拉鍊；並非實際接送 |

影片取 1080×800 上方畫面（保留原品牌角標、避開原底部字幕），縮至 810×600、24 fps、靜音，時間放慢為原長度的 1.5 倍，輸出 H.264 MP4。縮圖為各段起點加 0.4 秒的 WebP。五段短片合計約 2.39 MB，僅載入目前播放的片刻。

故事文案是設計提案，沒有宣稱為同一天的連續紀錄。家長問題列出可向園所了解的內容，正式整合時應依各校實際做法補上答案。

## 互動

- 六個縮圖分頁、上一段／下一段；手機橫向滑動。
- 分頁支援方向鍵、Home、End；原生 details 問答與 dialog 放大影片。
- 靜音影片可暫停；離開畫面、切換分頁與開啟對話框時停止背景播放。
- 偏好減少動態效果時預設顯示照片、不載入影片，使用者可手動播放。
- 影片失敗時保留照片；午休顯示明確標示的分鏡。
