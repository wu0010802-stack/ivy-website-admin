## D 版進度導航優化（2026-09-17）

園方選定 D 後，先精修時間節點。新增 `d-navigation.css`／`d-navigation.js`，D 的舊圓牌樣式已從 `directions.css` 移除。

- 半透明圓牌改為不透底的相紙標籤，時間與活動名稱不再被軸線穿過；桌機保留中央軸與左右照片。
- 目前片刻：暖黃底、實心點與「正在看」；已經過：勾記與「已走過」；接下來：空心點與片刻序號。狀態代表頁面閱讀位置，並非當下真實作息。
- 每個節點都是可定位到該片刻的連結；Tab／Enter 操作後保留焦點，螢幕閱讀器可取得順序、總數與 `aria-current="step"`。捲動不重複廣播。
- 手機時間標籤移到照片上方，軸線維持左側；活動名稱統一 14px，時間 26px，讓照片保留更多寬度。
- 沿用共用捲動計算，以 class 變化同步導航狀態；未增加第二組捲動計算。無 JavaScript 仍可用原生錨點，減少動態停用顏色轉場。

Chromium 驗證：1440／1024／768／390／320px 無水平溢出，節點皆大於 44×44px；六段正向與反向狀態、實際點擊、Tab／Enter 連續定位、減少動態、無 JavaScript 及強制色彩模式通過。節點文字對比最低 6.57:1。B／C 在 320px 的節點版面仍正常。Safari／Firefox 未實機驗證。
