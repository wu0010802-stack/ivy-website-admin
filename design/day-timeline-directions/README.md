## 第八輪：R 紙張翻面（three.js，2026-09-18）

使用者澄清「貼紙」指的是相片上方的紙膠帶：Q 已拿掉 `.washi`，號碼貼收回單一款。R `r.html` 與 Q 同版面，`round8.js`（ES module，從 jsDelivr 載入 three 0.170）把每張相片渲染成 WebGL 裡的一張紙：

- DOM 卡片保留，負責版面、鍵盤、`aria`；WebGL 初始化成功後加 `webgl-ready`，DOM 正反面透明化，畫布覆蓋其上（四周多留 70px 給彎曲與抬升，`.day-content` 以 `overflow-x: clip` 避免撐寬）。three 載入失敗或無 WebGL 時自動維持 Q 的 CSS 版。
- 正反面各是一張 2D canvas 畫成的貼圖（相紙漸層、照片、內陰影與光澤、橘色時間戳、號碼貼、小標與手寫標題；背面橫線紙與故事），`CanvasTexture` 貼在兩片 `PlaneGeometry`（28×28 分段）上。
- 顯影在貼圖裡進行：`is-revealed` 後 3.2 秒內逐幀以 `ctx.filter` 重畫照片並更新貼圖，時間戳在後 40% 浮現。
- 翻面：`round4.js` 切換 `is-flipped`，`MutationObserver` 接手做 1.1 秒緩動旋轉；中段紙面依 `x²` 彎曲（正反面反向位移、重算法線）並抬升 34px，落地時攤平。
- 光：環境光＋暖色平行光（投影到後方 `ShadowMaterial` 地板，抬起時影子變大）＋一盞跟著游標的點光源；游標移動時整張紙微傾（±0.28／±0.2 rad）。減少動態時不彎曲、不傾斜。
- 只有在動畫、傾斜或顯影期間才跑 `requestAnimationFrame`，靜止時不重繪；每張相片一個 renderer（六個 WebGL context）。

驗證（`../../output/playwright/day-timeline-round8/`）：Q／R 五種寬度無溢出、無 console 錯誤；閱讀狀態、鍵盤、翻面 `aria`、收尾連結、減少動態、無 JavaScript 通過。Headless Chrome 以 SwiftShader 確認六張皆 `webgl-ready`，中途翻面與懸停截圖 `r-flip-*.png`／`r-hover.png`。實機 GPU、Safari／Firefox 未驗證。

已知取捨：貼圖文字由 canvas 繪製，字體與 DOM 版略有差異，手寫標題超過兩行時會超出；六個 context 在低階裝置可能吃力，正式版應改成單一 renderer 多場景。收尾仍沿用 Q 的木盒，待使用者提供收藏感的參照。

各版標題文案都先用 `fontTools` 檢查落在 `day-font.woff`＋`lineseed-bd.woff` 的字集內（原始 LINE Seed OTF 不在本機，無法重建子集），因此四版名稱避開「鐘、篇、疊、蜿蜒」等缺字。

實作重點：

- E：`round3.js` 依閱讀線在六個時間點之間內插分鐘數，寫入 `--clock-minutes`，時針、分針與黃色弧線全由 CSS `calc()` 旋轉；沒有 JavaScript 時停在 08:00。手機把時鐘縮成貼在導覽列下的小條，右側留空給影片按鈕。減少動態時隱藏分針（轉八圈半太吵）。
- F：每段各自一段 `<svg preserveAspectRatio="none">` 曲線（桌機、手機各一組路徑），`pathLength="100"` 讓虛線與進度不受拉伸影響。支援 scroll-driven animation 時以 `view-timeline-inset: 50% 45%` 讓黃線隨閱讀線描繪；否則以 `is-past`／`is-active` class 切換。
- G：`position: sticky` 疊卡，第 n 頁的 `top` 多留 n 條標籤高度，標籤本身就是可點的 `.time-marker`。每頁下方留 45vh 讓讀者停留。共用控制器在進場錨點時會量到 sticky 後的位置，`round3.js` 在同一影格內捲回頂端重量測再捲回，不會閃。
- H：`.moment:hover`／`:focus-within` 展開故事；標籤是連結，觸控裝置點標籤即可展開。800px 以下改成單欄清單，故事直接顯示。
