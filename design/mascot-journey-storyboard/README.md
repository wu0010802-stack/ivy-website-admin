# 兩位小嚮導：首頁人物導覽分鏡

這是可捲動的設計分鏡，依目前首頁的 Hero、關於、孩子的一天、分校、消息、頁尾順序安排。頁尾預約邀請是新增提案；校園路線是概念示意，非實際地圖。此頁不代替主首頁。

## 故事與互動

- Hero 退場後，人物從品牌標誌的位置走出，品牌文字與徽章本身保持正式標示。
- 關於：照片旁探身、停下陪讀。
- 日常：兩人分開接力，配合日常內容的切換。
- 校園：一人沿五個校園選項移動，另一人指向下一步。
- 消息：在卡片邊緣探頭一次，然後停下。
- 頁尾：兩人會合，指向預約與機構社群。

正式設計採各區段「進入／閱讀／離開」的相對捲動進度，避免寫死頁面總高度。人物沿內容留白與相片邊緣移動；可互動的選單固定右上角。桌機人物建議視覺高度約 64–96px，手機約 44–64px。手機縮短路徑，以同側接力為主；偏好減少動態時改成各段靜態位置。

分鏡使用 CSS 原生 scroll timeline 驅動人物的 transform / opacity，具 feature detection 與 JavaScript fallback；瀏覽器減少動態偏好與頁面靜態開關皆可停用動態。原生捲動，不攔截滑鼠滾輪。分鏡展示分配等長章節，只用於比較；正式首頁依各區段自身高度計算。

## 素材

`characters.png` 是由內建 imagegen 依現有 `assets/logo.png` 產生的人物拆分示意，非正式品牌原稿。角色的走路、招手、閱讀等肢體動作，正式實作需分層的 SVG 或動畫角色原稿，不能只靠整張 PNG 平移冒充完成。

原始圖像：`assets/logo.png`。生成與清理提示見 `character-prompts.md`。圖稿需品牌確認；目前分鏡只示意角色位置、進退場與接力節奏。
