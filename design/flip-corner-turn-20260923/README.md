# 翻面動畫・角落起翻三版 — 2026-09-23（三版皆未採用：使用者裁定翻面維持不變，只在起步時讓右下角先捲，已接進 web/）

使用者在「風掀」提示（`../flip-wind-20260923/`）考慮 A 角落捲起，要翻面動畫也依 A 重做，三個 mock-up。

三版共同：
- 翻面提示就是 A：沒有折角，捲動時右下角被風掀起（參數同 flip-wind 的 A）。
- 點下去時都是**觀者看到的右下角先捲起**，再照現行方向「右緣掀起往左翻」整張翻過去；翻到背面再點，一樣是觀者右下角先起。
- 翻到一半再點會往反方向回到最近的整數半圈（連點幾次都不會停在半路）；紙膠帶畫在貼圖上跟著翻。
- 減少動態：不載 WebGL，維持 DOM 版 CSS 翻面、不起風。

| 版 | 名稱 | 做法 | 時長 |
|---|---|---|---|
| A1 | 捏角翻 | 右下角先捲（前 12% 只有角在動），整張繞中線翻；下半部比上半部轉得快（上下扭轉最多約 0.3 rad），過半回正、落地微微反扭 | 1.0 秒 |
| A2 | 對角翻滾 | 角先掀，整張沿「右上—左下」附近的斜軸（離垂直 35.5°）翻起、抬到 72px，後段轉軸以四元數曲線轉回垂直，落地時正著 | 1.15 秒 |
| A3 | 書頁翻 | 角先捲，捲曲擴大到七成寬（曲率較平均，像捲筒）；軸心先在左緣內側 0.42W，過半滑回中線，落回原位 | 1.1 秒 |

## 做法重點（接進官網時）

- `flipPose(type, p, W)`：p 是這半圈的線性進度，各版自己的緩動寫在裡面；回傳剛體姿態（四元數＋位移）與這一刻的角落捲曲、上下扭轉。**p=0 與 p=1 時所有變形都要歸零**，換面時才接得上。
- 變形在「翻面起點那一面朝向觀者」的座標裡算（x、z 乘 facing），所以不論正反面都是觀者右下角先起。
- 風的捲曲（提示）與翻面的捲曲取大的那個；翻面一開始，風的捲曲就讓給翻面。
- A2 的四元數要用不做半球修正的 slerp：兩個 180° 旋轉的內積為 0，three 的 slerp 可能走反方向。
- 踩過的坑：rAF 的時間戳是影格開始時間，可能早於點擊當下的 `performance.now()`，第一格進度會是負數，`rot` 跑到正數後索引算成 -1。進度要夾在 0–1。
- 畫布邊界：A3 翻到一半會往左超出卡片約 1/3 寬，A2 抬得高；本頁四周各留 160px。官網要確認不壓到隔壁欄、手機左側那張不被視窗裁掉。
- 手機捲動中官網是 CSS 版（沒有網格可彎），選定後要另談手機的做法。

## 檔案與預覽

- `index.html`／`mockup.css`／`mockup.js`：`?view=a|b|c` 單版並排；控制列有「慢動作」（×3）、「吹一陣風」、「全部翻一次」（每列同時翻、上下列錯開 0.25 秒）。`window.mockPose(p)` 把所有紙停在翻面進度 p（截圖用）。
- `shot.cjs`：`ONLY=film|live|mobile`。`film-a|b|c.png` 是翻面進度 0／0.08／0.16／0.26／0.38／0.5／0.62／0.74／0.86／1 的膠卷；`all-flipped.png` 實際點「全部翻一次」後；`mobile-a|b|c.png` 為手機在 p=0.38。逐格原圖在 `output/flip-corner-turn-20260923/`（gitignore）。
