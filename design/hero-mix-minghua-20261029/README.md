## 剪輯（`build.py` 的 `SHOTS`）

舊第 1 鏡（開場，封面不變）→ 老師擁抱 → 舉手 → 圍看色盤 → 大笑 → 紫色手掌 → 抬頭大笑 → 舊第 3 鏡（一起跑）。9.2 秒、276 格，比現行 9.83 秒短。

- 新片裁 1080:800 的框（與首屏同比例），預設 2160×1600 放在 y=461：上緣避開校徽、下緣停在字幕上方約 50px，**不補洞**。抬頭大笑要往上移（y=400），寬度縮到 1740、靠左，躲開右上校徽。
- 舉手那鏡只取 13.25–13.90 秒，之後有一隻手揮過鏡頭。制服女孩（35.8–37.2 秒）往右走出框，剔除。
- 新片以 BT.709 解（HD 成品、沒有標記），中間檔轉 BT.601 矩陣，後段跟舊片一樣以 BT.601 解回 RGB。舊鏡頭從園方原片重做的 FFV1（`design/hero-video-polish-20261024/build.py` 的 `lossless_shots`）。
