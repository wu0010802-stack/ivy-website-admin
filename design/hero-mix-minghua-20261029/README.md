## 剪輯（`build.py` 的 `SHOTS`）

抬頭大笑 → 踢足球 → 抱籃球 → 老師擁抱 → 盪架上的男孩 → 制服女孩大笑 → 圍著樂器大笑 → 舉手 → 圍看色盤 → 跪坐聽講 → 大笑 → 老師抱孩子 → 紫色手掌。第五版 12.43 秒、373 格（第三、四版 11.73 秒、352 格；第二版 9.2 秒）。第三版從老師擁抱開始，第四版只把循環起點往前轉三鏡，相鄰順序一樣。

- 裁 1080:800 的框（與首屏同比例），預設 2160×1600 放在 y=461：上緣避開校徽、下緣停在字幕上方約 50px，**不補洞**。抬頭大笑要往上移（y=400），寬度縮到 1740、靠左躲校徽。
- **開場＝封面**：第四版是抬頭大笑的第一格。第三版用老師擁抱，矮而寬的視窗（例如 1288×552）只看得到影片中段，整個畫面是老師的後腦；13 鏡各自當第一格套到頁面比過（1288×552、1440×900、390×844），抬頭大笑的臉在右、左邊是暗的樹叢，大標壓在樹叢上，三種視窗都不切臉。
- 老師擁抱從 3.02 秒開始。更早的格大半是老師的後腦。
- **跪坐聽講往下放大**（x=190、y=700、寬 1780）：y=461 時上緣一排窗戶正好在導覽列後面，導覽白字對比只剩 4.54。
- 舉手只取到 13.90 秒（之後有手揮過鏡頭）；老師抱孩子從 6.20 秒起（之前左側模糊手臂比較大）；抱籃球取到 40.70 秒（之後籃球被裁到）。
- 沒用的鏡頭：外師特寫（主角是大人）、戴口罩的孩子、低頭看不到臉、純手部特寫。

## 放慢第 3、4 鏡（第五版，`build.py` 的 `SLOW`）

使用者看過 13 鏡的清單後說第 3、4 鏡切太快。各鏡長度（第四版）：0.90／1.00／**0.60**／**0.70**／1.00／0.90／1.00／0.67／0.90／1.00／1.30／0.77／1.00 秒。

- 原片是快剪的廣告，每鏡大多只有 1 秒出頭。這兩鏡前後都沒有畫面可以多取：抱籃球之後孩子跳起來、臉被裁掉；老師擁抱往前是老師的後腦、往後 0.02 秒就換鏡。所以放慢播放：原片 18／20 格 → 30 格（0.59／0.66 倍速），兩鏡都變成 1.00 秒。
- 中間的格用 ffmpeg `minterpolate`（mci、aobmc、bidir）補。開頭先墊 n−1 格靜止，再把時間軸乘上 (k−1)/(n−1)：原片第一格、最後一格剛好落在輸出格線上，頭尾都是真實影格，不會補到隔壁鏡頭，也不會在尾巴凍格（逐格差異量過，沒有 0，也沒有跨鏡的尖峰）。
- 補出來的格 1:1 看過：籃球舉起來那幾格上緣有一圈很淡的殘影，播放時看不出來；老師擁抱沒有問題。
- 其餘 11 鏡與第四版逐格對過（新舊 H.264 對齊後最低 PSNR 46 dB，同一畫面兩次壓縮的差距）；封面（第 0 格）重產後逐位元相同，衍生圖與分享圖不用動。
- 原片還有餘裕、以後要再拉長可以直接多取的鏡頭：制服女孩大笑（往前約 1 秒）、跪坐聽講（往後約 0.8 秒）、大笑（往後約 1.6 秒）。
- 比稿與預覽在 Desktop 工作區 `design/hero-music-teacher-20261113/`（同一輪還試了加進崇德音樂老師兩鏡，使用者說先做放慢）。

## 色彩：照原片，不調色

原片沒有色彩標記，Mac 的 Chrome／Safari 以 BT.601 解再抬亮中間調。把這個「螢幕上的樣子」燒進像素（`design/day-film-color-20261025/screen-17.cube`，10-25 孩子的一天實測的 LUT），交付檔再標 BT.709 原色／矩陣＋sRGB 轉換函數，看起來就跟打開原片一樣。中間檔保留原片 YUV 值、不轉矩陣，後段跟瀏覽器一樣以 BT.601 解；明華 4K 縮下來沒有壓縮方塊，不去方塊。

**螢幕實測**：Chrome 原尺寸播放、同一格停格截圖，對沒有標記的原片（同裁切，`setpts=N/30/TB` 讓時間戳規則；concat 接起來的片時間戳有空隙，越後面越對不準）13 格：H.264 平均差 1.44/255（偏移 +0.01），AV1 2.01（偏移 −1.23）。比對影片要用支援 Range 的伺服器播，Python `http.server` 不能跳格。

**地雷**：各鏡中間檔格式要一致才能用 concat 複製串流接起來；第二版舊鏡頭串兩個 `lut3d` 時被協商成 `yuva420p10le`，接起來後段解碼報 `quant_table_index out of range`，所以中間檔輸出固定 `-pix_fmt yuv420p10le`。

## 封面與分享圖

`hero-campus-restored-v1-still.webp` 是中間檔第 0 格（`build.py` 的 `poster`），換片後跑 `optimize-site-images.py --only hero-campus-restored-v1-still` 重產衍生圖與分享圖，再手動刪掉沒被 `image-manifest.json` 引用的舊衍生圖。封面接影片第一格平均差 2.55/255。

分享圖（1200×630）全站固定以垂直 40% 為中心裁，第三版那張的孩子臉在下半，會切到嘴；`optimize-site-images.py` 加了 `OG_CENTERING`，只有首屏這張用 75%。第四版的封面沿用 75%，整張臉都在。

替代文字（`site-fixture.json` 的 `heroImageAlt`，後台沒設首屏封面時用它）第三版是「常春藤的老師抱住孩子們、大家笑成一團的校園影片畫面」，第四版改成「常春藤的孩子抬起頭開心大笑的校園影片畫面」；`web/tests/fixtures/overlay-baseline-20260925.json` 同步。
