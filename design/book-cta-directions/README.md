## 現況的問題

1. **它讀起來是第五個導覽項。** `studio.css:21` 讓 `.header-label` 與 `.nav-inner>a` 共用同一套排版（中文在上、英文在下、置中），CTA 的內部結構和「最新消息」一模一樣，只多一個框。
2. **打勾圖示語意相反。** 原本是 `#i-check`（已完成／已選取），這顆是「去預約」。sprite 裡閒置的 `#i-calendar-check` 才對；五個方向都已換掉。
3. **最弱的長相在第一眼。** 首屏透明框 → 往下捲 40px（`COMPACT_AT`）整條頁首讓位給深綠膠囊上的**暖黃**預約鈕。`studio.css:206` 那組「捲動後變綠實心」在首頁其實看不到，因為 `is-scrolled` 和 `data-state="compact"` 同時觸發、頁首同時被收起——那組規則只對分校頁與預約頁有意義。
4. **白字透明底壓在影片上。** 只靠 `--hero-line`（60% 白）撐邊框，影片亮幀時幾乎消失，非文字對比 3:1 過不了。

## 實作上的幾個點

- **特異性**：站內 `body:has(.studio-hero) .header.is-scrolled .header-book` 是 (0,4,1)，比 `[data-book="x"] body:has(.studio-hero) .header-book` 的 (0,3,1) 高，捲動狀態要另外明寫一條才蓋得掉。
- **e 的 DOM 是全站一次性的**：`app.js` 在載入時把 CTA 包進 `.book-stack` 並加上致電那行，分校頁也會有；所以 `.book-stack`／`.book-alt` 的排版規則**不加** `body:has(.studio-hero)` 前綴，只有換色那幾條加。否則分校頁會掉出一行沒樣式的裸連結。
- **e 的按鈕會斷字**：直排後 `align-items:stretch` 讓寬度被父容器限住，手機上「預約參觀」會斷成兩行，`.book-stack` 要補 `white-space:nowrap`。
- **d 在手機沒有貼邊的位置**：右邊還有漢堡，滿高色塊會夾在 logo 與漢堡之間；900px 以下降級成 a 的黃膠囊（`height:auto`＋`border-radius:10px`，`.header-actions` 收回 `align-self:center`）。

## 第二輪：形狀（`?book=d1`–`d12`、`dx`）

園方選定 d（金色滿高色塊）之後，剩下的題目是形狀。**比圓角半徑更早要決定的是貼哪一邊**：

- **`d1`–`d8` 貼內容欄右緣**（和膠囊、原本的預約鈕同一條線）：右邊留一段底圖，色塊像浮在頁首上的一張卡。d1 對稱圓角 16／d2 直角／d3 深圓角 28／d4 半圓底／d5 左下大圓角／d6 右下大圓角／d7 吊牌／d8 斜切。
- **`d9`–`d12` 貼視窗右緣**：色塊成為頁首結構的一部分。右緣一旦貼邊，右下角就不該再有圓角，形狀自由度只剩左邊與下緣。d9 左下 44／d10 左緣斜切／d11 貼邊吊牌／d12 左下 96 長弧。**代價是頁首底線跟著拉成滿版。**
- **`dx` 是可調版本**，形狀參數全走 CSS 變數，配調校頁 `tuning.html`（左下／右下圓角、垂出底線、左右內距五個滑桿，即時改 iframe 裡真正的首頁，同步吐出可貼回 `studio.css` 的片段）。

建議 **d12 或把弧再拉長到 120–130**：貼邊後色塊才是頁首的一部分；左下長弧呼應站內既有語彙（首屏照片 `45% 45% 3px 3px`、品牌區照片 `5px 5px 65px 5px`）而不是通用按鈕圓角；弧開在左下把視線從邊緣收回內容。次選 d11 吊牌。可淘汰 d2、d8、d4。

### 貼邊的實作陷阱

- **不能用 `.header-book` 的負邊距**：`max(48px,calc((100% - 1280px) / 2))` 裡的百分比是在**使用它的元素**上解析的，`.header-book` 的包含塊只有 200px 寬，`max()` 會一路退回 48px，色塊差 30px 貼不到邊。改成把 `.header-top` 從置中容器換成滿版、左邊補回 gutter，百分比才是對 `.header`（寬度＝可視寬，也避開 `100vw` 的捲軸誤差）。
- **滿版規則要包在 `@media(min-width:901px)`**：寫在 `max-width:900` 裡還原容器寬度會蓋掉 760／380 斷點各自的 `.container` 寬（40px／32px gutter）。

### 同日追加：分校頁與預約頁也換成同一顆

原本 d9 只套在有 `.studio-hero` 的首頁，全站有兩種長相。已把規則從首頁專用區段移到共用區（選擇器去掉 `body:has(.studio-hero)` 前綴），分校頁與預約頁的米白頁首上也是同一顆金色滿高色塊（`shots/unified-campus.png`、`shots/unified-visit.png`）。
