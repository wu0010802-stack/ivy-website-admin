# 30 週年分頁「磅礴版」mock-up（2026-10-24）— 待使用者看過

使用者：「再做一版 30 週年分頁的 mock-up，想嘗試磅礴一點的感覺。」現行 `/anniversary` 是「孩子畫出的 30」（蠟筆、紙偶、立體卡片），這版換一個方向：**用真實校舍照與影片撐出尺度，鏡頭一路拉遠**。只是比稿，`web/` 沒有改。

## 五段

1. **鑽進 30**：首屏是一個巨大的「30」，筆畫裡播首頁首屏那支孩子奔跑的影片（遮罩是 LINE Seed TW ExtraBold 的輪廓，不靠字型載入）。往下捲，鏡頭直直鑽進 0 的左邊那一筆，影片變滿版，再浮出三行字：「1997 年，第一間常春藤／在高雄三民區義華路成立，／到 2027 年滿 30 年。」
2. **橫走 1997 到 2027**（≥900px 寬）：往下捲推著軌道往左。五校成立那年是一整個畫面的校舍照＋巨大年份（照片比面板慢、年份比面板快，有前後景）；其他年份是窄窄的直排數字，讀線經過就從空心描邊變實心深綠——2006–2019 那十四年一下就刷過去。左上計數列：31 格刻度、金點、「第 N 年・N 所校園」，2027 寫「滿 30 年」。走到 2027 是五校並排的直條（滑鼠移上去會展開），標題「現在高雄有五所常春藤」。手機改直向：校舍照在上、資料在下，空白年份排成一行行數字，計數列黏在畫面底。
3. **照片牆拉遠**：一開始是滿版的一張（孩子圍著大人笑），往下捲拉遠成 15 張真實照片的牆，最後罩上墨綠、浮出「陪高雄孩子近三十年」（09-23 定案的首屏小標）。
4. **終章**：全頁唯一的深色段。墨綠底、金色放射光慢轉、背後一個金色細線的巨大「30」，30 週年校徽放在米白圓章裡升上來，接「2027 年，滿 30 年。」與預約。
5. 預約參觀＋頁尾。

## 內容只用現有的

年份、民國年、沿革句與 /about 第一章（`utils/anniversary/timeline.ts`）一字不差；地址電話取 `site-fixture.json`；首屏三行拆自現行頁的 `HERO_LEAD`；結尾句與預約文案照現行頁。沒有寫活動、人數、故事，也沒有「美語部」「補習班」「三十多」。照片全是 `web/public/assets` 裡已上線的園方照片，只縮小、沒調色。

## 規則對照與取捨

- 顏色值照抄 `tokens.css`；金色只用 `--gold`，壓暗只用 `--ink`／`--ivy-forest-rgb`。
- 10-20 剛把全站調亮，這版除了終章都是亮的；終章的墨綠是刻意的「典禮感」，如果覺得太暗可以改成米白底＋金章。
- 減少動態／沒有 JS：不釘住、不橫走、影片不自動播，照片牆直接是拉遠後的樣子，所有文字都讀得到。
- 鑽進 30 改的是 `mask-size`／`mask-position`（不影響版面，不會有 CLS）；正式做時要在實機量效能，必要時改成 transform。
- 五校預約鈕統一寫「預約參觀Ｘ校」；正式做要照 10-24 的參觀方式規則（暫停或來電的校區改「致電Ｘ校預約參觀」）。
- **現行頁的這些這版沒放**：開場影片《手牽手，走到 30》、孩子畫的高雄地圖、30 支蠟燭、作品拼成的 30、換你畫一個 30。要整頁換掉，還是把這版的某幾段併進現行頁，待使用者決定。

## 驗證

- Playwright（Chromium）1440×900、390×844 逐段截圖；減少動態整頁截圖。沒有橫向捲動、沒有 console 錯誤。
- **未驗證**：Safari／iOS 實機（影片上的 CSS mask、`backdrop-filter`）；headless Chromium 播不了 H.264，影片只看過封面那一格；真機捲動效能。

## 開啟與重產

`index.html` 是 Artifact 的頁面內容（沒有 `<html>`／`<head>` 外殼）。本機看：

```sh
python3 design/anniversary-grand-mockup-20261024/serve.py design/anniversary-grand-mockup-20261024 8791
# http://127.0.0.1:8791/
```

素材（縮圖、影片、字型分片與 `@font-face`）由 `build-media.py` 產生，指令寫在檔頭；改了頁面文字要跑 `--fonts-only` 補字型分片。
