## 驗證（2026-09-24，Chrome via Playwright）

- 18 案 × 320／390／768／1440px 共 72 筆：無橫向溢出、LINE Seed 載入成功、導覽與五校連結高度皆 ≥44px、無頁面錯誤或資源載入失敗。
- 對照頁：勾 D、S 後「候選」只剩兩案、「雙色」只剩 R／S／T、重新載入保留篩選與勾選、取消後歸零；全部顯示時沒有高度為 0 的預覽框。
