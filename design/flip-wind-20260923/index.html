拍立得翻面・拿掉折角

平常是一張完整的相片，
風來了才掀起背面。

三版都沒有折角。捲動時被風從牆上掀起來，
掀過頭就露出背面的橫線紙，風停就平貼回去。

三版比較ABC
同兩張相片，三個被風掀起的部位 · 請上下捲動，或按「吹一陣風」
相片與故事取自官網 fixture整張可點 · 觸控與鍵盤可翻面 · 減少動態不播動畫

「靜止時微風」是另一個獨立決定：開了之後，停止捲動 2 秒，每 5–9 秒有一陣微風從右往左掃過畫面裡的相片（會自己動，但不翻面）。預設關，只回應捲動。

本頁用 three.js 紙張網格示意，貼圖畫法同官網 paperPrints.ts；手機捲動中官網是 CSS 版，選定後另做 CSS 近似。
