使用者附「01 早安入園」截圖：**把折角拿掉，改用風把紙掀起來的效果**當翻面暗示。平常是一張完整、平貼的相片；捲動時被風從牆上掀起，掀過 90° 就露出背面的橫線紙（B 還看得到故事文字），風停平貼回去，不留痕跡。

共同：觸發是頁面捲動（速度→風力，起 70ms、收 600ms）；「靜止時微風」是獨立開關，預設關（開了之後停止捲動 2 秒，每 5–9 秒一陣 2 秒的微風，從右往左掃過畫面裡的相片）。減少動態不載 WebGL、不起風。翻到背面時風一樣往觀者這邊掀。

## 做法重點（接進官網時）

- 彎曲剖面：離折線 u 處轉角 θ(u) = hinge·(1−(1−u)³) + tip·u³。轉角集中在折線附近、外側近乎一整片（像被風翻起的一頁），tip 為負＝末端逆風回彎。第一版用 φ·u^p（越到末端越彎），結果只有尖端翻過 90°，從正面看只像缺角，**看不出背面**。
- 沿邊緣的波：K=7 組「轉角 ×(1±ripple)」的積分表，逐點在兩組間內插；每幀每張重建約 2k 次三角函數。波幅超過 0.2 會像布不像相紙。
- 兩段彎曲可疊：先算局部（角／右緣／下緣），再把結果沿整張離牆那段的局部法線轉過去（C 用）。
- 光源：環境光 1.35→0.9、主光 1.6→2.1，平貼時亮度不變，彎曲處才有明暗；紙面 `receiveShadow` 讓捲起那塊把影子投在自己身上（bias −0.0006、normalBias 0.6 沒有 acne）。
- 同一張網格兩個 mesh：正面 FrontSide、背面 BackSide＋貼圖 `repeat.x=-1`（背面貼圖是從背面看畫的）。
- 接官網：`paperPrints.ts` 的 `bend()` 目前只有翻面懸臂彎，要加這套風的變形；`earGust.ts` 的彈簧改推 hinge／reach／billow；折角（`--ear`、`cutEar`／`drawEar`、`.print-ear`、進場掀角 `runPeel`）全部移除。手機捲動中是 CSS 版，沒有網格可彎，需要另做近似（或捲動中也保留 WebGL，要量效能）。
