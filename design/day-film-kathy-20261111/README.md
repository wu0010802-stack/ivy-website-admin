# 常春藤的一天背景：明華〈2024幼幼班介紹Kathy〉六鏡「小手與背影」版（2026-11-11 比稿）

11-11 使用者給園方雲端〈2024幼幼班介紹Kathy.mp4〉問能不能剪成常春藤的一天。查證後它就是 11-05 比稿用過的明華 FB〈幼幼寶貝的快樂生活〉同一支成片（同長度 186.92 秒、同畫面、校徽字幕一樣燒在裡面，只差碼率）。11-05 那版（明華＋仁武 12 鏡）在 11-10 被否決：「畫面太亂」。使用者同意用這一支單獨再剪一版，條件是剪法要明顯不同。

**2026-11-12 定案**：使用者說「先做明華幼幼・六鏡（紗不加重）」，也就是下表的 `handsraw`。已接上 `web/`（`feature/day-film-kathy-20261112`，見根目錄 README 同日段落）；`hands` 的加重紗沒有做進正式站。

看比稿（正式站首頁鏡像，左下角切換）：

```sh
python3 -I design/day-film-kathy-20261111/serve.py   # http://127.0.0.1:8878/?daybg=hands
pkill -f "day-film-kathy-20261111/serve.py"
```

| `?daybg=` | 內容 |
|---|---|
| `hands` | 六鏡片＋拍立得上來後深綠紗加重 |
| `handsraw` | 同一支六鏡片，紗不加重（對照用） |
| `current` | 正式站現行（義華遊藝表演） |

手機要用開發者工具切到 760px 以下才拿直式檔。鏡像只轉 GET、telemetry 與 POST 吞掉；圖說在鏡像裡暫改成「明華校 · 幼幼班的一天」。

## 六鏡（`build.py` 的 `CLIPS`）

| 時段 | 鏡頭（片源秒數） | 倍率 | 備註 |
|---|---|---|---|
| 08:00 早安入園 | 校門口，老師蹲下來抱住孩子（141.00–142.95） | 0.42 | 孩子背對鏡頭、側臉；142.95 之後老師正臉入鏡，剪掉 |
| 09:10 好奇探索 | 小手把形狀放進套盒（133.56–135.70） | 0.45 | 沒有臉 |
| 11:40 一起用餐 | 孩子背著手排隊（28.80–31.20） | 0.5 | 沒有臉。**不是用餐畫面**：這支片的用餐鏡頭都拍正臉，第一版用「老師遞碗、孩子自己吃」（83.34–85.08），放上頁面後男孩的臉佔右邊快兩成寬，換掉 |
| 12:30 安靜片刻 | 沒有人的遊戲場，薰衣草在溜滑梯前晃（0.06–1.92） | 0.4 | 片裡沒有午休或看書，用空景代替 |
| 14:20 午後玩耍 | 紅磚牆前，孩子溜下滑梯跑開（38.75–40.35） | 0.4 | 遠景，孩子笑著但臉小 |
| 16:30 帶故事回家 | 孩子坐在鞋櫃前自己穿鞋（78.76–80.18） | 0.38 | 沒有臉；片裡沒有放學畫面，用穿鞋代替，溶回早上校門口 |

- 裁切一律躲開左上校徽（x 165–1102、y 90–281）與底部字幕帶（90.4–94.4% 高）：桌機從 4K 裁 2880×1620 縮到 1440×810；手機裁 1085×1929（或從校徽下方起裁 918×1632）縮到 720×1280。`build.py review` 會畫出裁切框檢查。
- 沒用的：戴口罩的鏡頭、老師訪談、家長戴安全帽交接、用餐與教具操作的近景正臉（最多的一類）。
- 背景影片自己循環，沒有跟拍立得的時段同步，所以「時段」只是排鏡頭順序的依據。
- 片源沿用本機 `output/day-fb-src-20261105/fb-minghua-815137417136803-3840x2160.mp4`（FB 版 4K AV1）。Drive 母檔是 H.264 82 Mbps、1.9 GB，縮到背景尺寸看不出差別，沒下載保留。

## 色彩與亮度

照 11-05：以 BT.601 解 → `screen-17.cube`（沒標記影片在 Mac 上的樣子，照原片色調）→ `EXPOSE` → 標 BT.709 原色／矩陣＋sRGB 轉換函數。桌機的校門口擁抱與套盒偏亮，另壓（`TONE_DESKTOP`）。

## 加重的紗（`kathy.js`／`kathy.css`）

11-10 查到「太雜、無法聚焦在拍立得」的原因之一是正式站的深綠紗在大標淡掉後反而變輕。`hands` 沿用 11-10 第七輪 `focus.css` 共用的那層：`.day-film-shade::after` 疊一層 `--deep`，不透明度跟著大標淡出的進度（`--word-fade`）從 0 走到 .46；不模糊、不去色。開場大標那一屏跟正式站一樣。
