## 接進官網前要決定的事

- **牴觸 09-16 裁定**：DESIGN.md「最新消息：採用 A 版（2026-09-16）」寫明「不使用自動輪播」。「有輪播、不要按鈕」就等於自動換，三版都會自動播放，選定任何一版都要重新拍板、並回改 DESIGN.md 那一節。同日另一個 session 在做手機版（`design/news-carousel-mobile-20260923/`），桌機與手機定案後要一起對齊。
- **自動輪播的暫停機制**：WCAG 2.2.2 要求超過 5 秒的自動移動內容有暫停／停止方式。目前只有 hover／焦點暫停，沒有常駐的暫停控制；使用者要求不要按鈕，上線前要選一種：播完一輪就停、或保留一個很小的暫停鈕、或接受只靠 hover 暫停。
- 手機版現況是 scroll-snap 橫向滑動（`studio.css` ≤760px），本次沒有動。
- 接官網的位置：`web/app/components/NewsDialog.vue` 的 `.hn-cards`（現在是 `news.articles.slice(0, 3)`），樣式在 `web/app/assets/css/studio.css` 第 42 行起的 `.home-news`／`.hn-*` 規則與 `typography.css` 的 News 字級。
