現行 `/admission` 沿用分校頁版型（白底頁首、框在麵包屑下的 hero、明體大標、米色分頁列、一般卡片格線）。這份 mock 把首頁的版型語言套到入學資訊的內容上，**內容不變**（取自後台 `admission_content` 預設值），只換版面與節奏。

> **2026-09-24 已依此 mock 改正式頁**（見 DESIGN.md「入學資訊頁 /admission 改首頁版型」）。與 mock 的差異：「金額以公告為準」提醒放在 hero 動作鈕下方（不是收退費標題旁）；hero 照片沿用 `day-hello`、`day-discover` 移到入學流程；hero 小標改內文粗體；膠囊裡沒有做「目前章節」。下方「要你決定的地方」第 1–4 點都照 mock 採用。

## 順序調整

入學流程 → **分班對照** → 新生準備 → 收退費。家長看完流程最先問的是「我家寶貝讀哪一班、哪年可以進來」，所以把分班提到第二段；hero 的「查寶貝讀哪一班」也跳到這裡。

## 要你決定的地方

1. **大標字體**：mock 用首頁的 LINE Seed 700。DESIGN.md「入學資訊頁」（2026-09-24 上線版）定的是 hero 明體大標，另切了 `noto-serif-tc-500-admission.woff`；採用這版就要改那條，明體子集也可以刪。
2. **桌機收膠囊**：目前定案是桌機內頁不收；mock 讓入學資訊跟首頁一樣收，膠囊裡顯示章節。若只有首頁收，章節索引就只剩 hero 那一排。
3. **拿掉黏性分頁列**：改成 hero 章節索引＋膠囊章節名。頁面長，若覺得跳段不夠方便，可以把膠囊的章節名做成下拉選單。
4. **「金額以公告為準」提醒**：從頁首黃條改成收退費標題旁的小膠囊＋頁尾小字；園方確認金額後照舊在後台清空。
5. **hero 照片**：repo 裡沒有夠大的橫幅照片，暫用 `day-discover`（1080px）放大。正式版要換一張 1600px 以上的，並依規則用實際像素量遮罩對比。
