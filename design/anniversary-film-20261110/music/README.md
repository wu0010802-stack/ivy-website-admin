# 配樂《長成自己喜歡的樣子》

常春藤 30 週年紀念影片的原創配樂。90 BPM、4/4、D 大調，長 2 分 24 秒（54 小節）；高潮第 36–43 小節升到 E 大調，
第 43 小節的 A 和弦（E 的 IV＝D 的 V）轉回 D。**一小節 = 8/3 秒 = 30 fps 的 80 格**，第 n 小節（0 起算）在 `n × 8/3` 秒。

## 結構（對應 `../TREATMENT.md` 的分鏡）

| 小節 | 時間 | 音樂 |
|---|---|---|
| 0–7 | 0:00–0:21 | 鋼琴獨奏。四小節動機「A–D–F♯–E｜E—A」（5-1-3-2，像嫩芽往上長）＋「B–D–F♯–A｜G—F♯E」，後四小節收在 Asus4→A。第一個音在 0.000 秒，之前沒有任何聲音 |
| 8–11 | 0:21–0:32 | 動機再來一次，左手改八分音符滾動琶音；中提琴、二部小提琴、大提琴的長音淡入。**2001（第 8 小節）、2005（第 10 小節）各有一聲鋼片琴**，第 8 小節前有豎琴刷奏與很輕的升起聲 |
| 12–13 | 0:32–0:37 | 年份滾動：撥弦「滴、答」＋鋼琴 A5 輕敲，**14 個八分音符＝2006…2019**（第 12 小節第 0 拍起每 1/3 秒一下），最後半小節停一下 |
| 14–17 | 0:37–0:48 | 2020（第 14 小節）、2021（第 16 小節）各一聲鋼片琴；第一部小提琴進來 |
| 18–19 | 0:48–0:53 | 五校全景：Gadd9 的溫暖大和弦（低音提琴、法國號、定音鼓滾奏接進來、鐘琴一點、鈸輕輕一刷） |
| 20–33 | 0:53–1:31 | 第三幕：大鼓心跳、搖鈴、大提琴撥弦；第 24 小節起第一部小提琴高八度唱旋律，第 28 小節起鋼琴旋律加八度、鈴鼓、合奏撥弦、豎琴分解和弦、鋼片琴跟旋律 |
| 34 | 1:31 | 手牽手：打擊全停、弦樂一下收小，只剩鋼琴 |
| 35 | 1:33 | 低音 G–A–B 往上推（定音鼓滾奏、大鼓漸強），升到 E 大調 |
| 36–41 | 1:36–1:52 | 高潮：E 大調的動機，小提琴與鋼琴同度唱、二部小提琴低八度、法國號墊和聲；第 39 小節定音鼓滾奏＋反向鈸＋升起聲接進**第 40 小節最高點（鈸）** |
| 42–43 | 1:52–1:57 | 片名句：A(add9) 全樂團最寬的和弦（低音 A1 到小提琴 A5、豎琴刷奏、鐘琴）；第 43 小節的 A 當作 D 的屬和弦 |
| 44–49 | 1:57–2:13 | 一下收回只剩鋼琴與弦樂長音（低頻輕輕一下），開場動機回來。**星星：第 45 小節第 0、1、2、3 拍與第 46 小節第 0 拍**，鋼片琴＋鐘琴 A5→D6→F♯6→A6→D7；**第 47 小節 30th 緞帶**：鐘琴快速上行＋金色閃光聲；第 49 小節 G→Gm6（小調 iv，降 B 落到 A） |
| 50–53 | 2:13–2:24 | 最後的 D(add9) 和弦（鋼琴滾奏、豎琴、弦樂、定音鼓），自然延音，最後 2 秒淡出到 144.000 秒 |

所有提示點的秒數與 30 fps 格數在 `score-master.json` 的 `hits`。

## 樂器

- **鋼琴**：Salamander Grand Piano V3（OGG，力度層 3／6／9／12／15＋制音器聲），自寫取樣器 `sampler.py`：
  每小三度一個取樣、±1 半音三次內插重取樣；依目標音量選力度層再補增益（不在兩層間交叉混合，避免梳狀濾波）；
  延音踏板、依音高調整的制音器衰減、F6 以上不止音、同鍵再敲時打斷前一次振動；取樣開頭的 9–14 ms 空白已切掉，音頭對準拍點。
- **其他**：MuseScore General（`MuseScore_General_Full.sf2`）以 fluidsynth 2.3.4 逐軌渲染（48 kHz float，內建殘響與合唱關閉）。
  弦樂用分部音色：小提琴一部（bank 20）、二部（25）、中提琴（30）、大提琴（40）、低音提琴（50），長音用 Slow、旋律用 Fast；
  另有合奏撥弦、大提琴撥弦、豎琴、鋼片琴、鐘琴、定音鼓、法國號、Orchestra Kit（大鼓、鈸、搖鈴、鈴鼓、三角鐵）。
  弦樂依交響樂團座位放聲像（一部左、二部左中、中提琴右中、大提琴右、低音提琴右）。
- **音效**（numpy 合成）：第 8、20、34、40 小節前的升起聲（時變帶通雜音），第 44 小節的低頻、第 47 小節的金色閃光；
  反向鈸接進第 20、36、40、42 小節。

## 混音與母帶（`mix.py`）

- 音量不寫死數字：`BALANCE` 寫的是「在哪幾小節裡、比鋼琴小幾 LU」，程式量 K 加權響度後換算增益。
- 起音慢的取樣整軌提前（Slow 弦樂 90 ms、Fast 45 ms、法國號 40 ms、撥弦 6–8 ms），和聲換在拍點上。
- 各軌 EQ（鋼琴 280 Hz −2.5 dB、小提琴 2.8 kHz −2 dB 等）、合成的音樂廳殘響（四頻段不同衰減，RT60 約 2.2 秒、
  前置延遲 20 ms、七個早期反射）、匯流排 2.4:1 壓縮、4 倍超取樣的真峰值限幅（4 ms 前視）。
- 目標 −14 LUFS、真峰值 −1.2 dBTP，48 kHz／24-bit。

| 項目 | 結果 |

| 整體響度 | −14.03 LUFS |
| 真峰值 | −1.20 dBTP（4 倍超取樣） |
| 削波、NaN | 0 |
| 限幅器 | 最多 4.3 dB，只在第 39–42 小節的定音鼓與鈸上（全片 0.03% 的取樣接近天花板） |

| 提示點音頭 | 30 個量得到的提示點都在 ±10 ms 內（最大 8.9 ms）；第 18、34、36 小節前面是漸強滾奏或延音，量不到獨立音頭 |

每 4 小節的響度（LUFS）：0–3 −22.5、4–7 −21.2、8–11 −18.8、12–15 −18.4、16–19 −14.9、20–23 −16.4、24–27 −14.7、

**沒辦法驗證的**：這些都是量測，沒有人耳試聽過。音色是取樣音源，分部弦樂的連奏沒有真正的換弓與滑音。

## 重做

```bash
cd design/anniversary-film-20261110/music
nice -n 5 python3 render.py   # 總譜 → MIDI → 各聲部 stem（約 30 秒）
nice -n 5 python3 mix.py      # 混音、母帶、檢查（約 1 分鐘）
```

需要：`apt-get install fluidsynth musescore-general-soundfont-lossless`、`pip install mido soundfile pyloudnorm scipy`，
Salamander 取樣用 `npm pack @audio-samples/piano-velocity{3,6,9,12,15} @audio-samples/piano-release` 解開，
路徑用環境變數 `SALAMANDER_DIR` 指定。

輸出在 `output/anniversary-film/music/`（已 gitignore）：`score-master.wav`、`score-master.json`、
`groups/{piano,strings,colour,percussion,sfx}.wav`（含各自的殘響，加起來約等於限幅前的母帶，給剪接時重新平衡）、
`stems/`（未處理）、`analysis/{waveform,spectrogram}.png`。
