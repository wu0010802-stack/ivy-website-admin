## 首屏主視覺（2026-09-14 審查後定案）
審查結論：版型（左對齊、手繪底線、中文手動斷行）沒問題，問題出在「先把素材壓暗再放白字」的深色影片 hero 反射，使真實校園照失去日光與品牌色。以下為修正後的規則。

- **遮罩只保護文字，不蓋整個畫面。** `.studio-hero::before` 改為三條各自對應一個可讀性需求的帶：頁首帶（頂部 96px 實心、200px 內淡出）、底部說明列帶（250px）、左側文字欄帶（0–34% 實心，72% 歸零）。全部走 `rgb(var(--ink) / a)`，不再出現 `rgb(0 0 0 / a)` 或 `#fff` 字面值。孩子的臉所在的右側維持全日光。
- **數值依實測照片亮度決定，不憑感覺。** 桌面白字對 `assets/hero.webp` 的平均對比：導覽 5.78、eyebrow 4.65、預約鈕 5.01、副標 6.08，全部過 4.5:1。改動遮罩後必須重量，勿只憑肉眼。
- **手機不做滿版壓字。** 2.49:1 的橫幅照片放進 0.46:1 的手機首屏，孩子的白色制服正好落在文字位置，實測副標對比只有 2.66，加厚遮罩會把照片壓死。改為：照片佔上方 `clamp(180px,100% - 500px,46%)` 的帶（`object-position:82% center`），下緣淡入 `--deep`；文案、影片說明列、底部列全部落在深綠面板上，白字對比 13.8:1。照片因此從放大 1.46 倍變成縮小 0.6 倍，可見範圍從原圖寬度 19% 提升到 46%，臉不再被裁。
- **主要行動只有一個主色。** hero 主鈕 `background:var(--yellow);color:var(--deep)`（9.65:1），文案「預約來校園走走」明說是預約；頁首「預約參觀」維持白框幽靈鈕當重複入口。焦點環 `outline-offset:5px` 落在按鈕外的深色底上（13.97:1），不壓在黃色上。
- **品牌色在 hero 至少留一筆**：`慢慢長大` 的手繪底線 `stroke:var(--yellow)`。其餘文字維持白色。
- **一屏只留兩句**：h1 與副標。已刪除 `.hero-note`（原「給孩子，一個喜歡上學的理由。」）。底部左側改放校區資訊「五所校園：三民 · 左營 · 鳥松 · 仁武」，同時回應比較型家長；不再限制 `max-width:14ch`。
- **狀態文字不得超前畫面。** `#media-caption` 預設「義華校 · 生活影像」，只有在 `video` 的 `playing` 事件後才改成影片文案；減少動態、省流量、慢速連線與載入失敗時都維持海報文案。自動播放除 `saveData` 外也擋 `effectiveType` 為 2g／3g。
- **hero 高度必須收進一屏**：`.studio-hero-grid` 的 `padding-block` 改 `clamp(28px,5vh,56px)`。1280×800 與 1440×900 實測皆為單屏，暫停鈕不再落在摺線下。
- **素材規格（待園方提供）**：海報原圖至少 2400px 寬；另需一張直式校園照供手機使用；影片至少 1920×1080，並另備直式版。首屏影片現為園方廣告片剪出的 `assets/hero-campus.mp4`（見下方 2026-09-15 節）。
- **已移除的死碼**：`.paper-sun`、`.hero-sprout`、`.studio-hero-image figcaption`（DOM 中皆不存在）。`.seed-dot`（eyebrow 前的裝飾圓點）依「圖示只出現在動作旁」規則移除。
- **打包器**：`package_preview.py` 原本只內嵌 `styles.css`，會讓 `preview.html` 完全失去工作室主題；已修正為同時內嵌 `studio.css`。

## 首屏字型、按鈕與校園影片（2026-09-15 定案）
- **標語字型**：維持 LINE Seed TW ExtraBold 800；尺寸 `clamp(2.5rem,1.55rem + 3.6vw,4.6rem)`（1440px 時 73.6px）、行高 1.24、字距 .01em，陰影改為柔一點的 `0 2px 28px` 加 `0 1px 2px`。句尾標點（，。）以 `.punct{margin-inline-start:-.24em}` 收進來：子集字型雖列有 `halt`／`palt`，實測在 Chrome 無效（「，」「。」仍是 1em 全形），所以用負邊距而不是 OpenType 特性。手繪底線只畫在「慢慢長大」四字下，句號在底線外。
