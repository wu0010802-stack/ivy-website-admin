## 可讀性與觸控底線（2026-09-10 審查後定案）
- 中文說明文字（圖說、頁尾、麵包屑、提示）最小 12px（.75rem）；只有裝飾性英文小標可低於此值。
- 所有可點元素高度至少 44px；行內文字連結用 `padding-block` 搭配負 `margin-block` 撐出觸控範圍，不改變版面。
- hero 只設 `min-height`、不設固定 `height`，文字放大到 200% 時不被裁切。
- 深色遮罩、淺色文字、錯誤色、時間軸顏色一律走 `--ink`、`--mint`、`--error`、`--trail` token，不再散落 rgba／oklch 字面值。

## 中文優先與箭頭規則（2026-09-10 定案）
- 段落小標（.eyebrow）一律中文短語，對應導覽或子導覽的名稱；英文只保留在品牌名（頁尾 IVY KINDERGARTEN、logo）。導覽列不再放英文副標。
- ↗ 只用於離開本站的連結（機構原官網、義華校活動頁、Google 地圖）。
- → 與 ← 只用於有順序的操作：預約表單的上一步／下一步、孩子的一天的前後片刻。其餘按鈕與文字連結不加箭頭。

## 圖示（2026-09-10 定案）
- 全站使用 Phosphor Regular 單一套圖示，經 Iconify 取得後以 SVG sprite 內嵌在 `index.html` 的 `<body>` 開頭；JS 以 `icon('name')` 輸出 `<use>` 引用，不引入任何 runtime。
- 圖示只出現在動作旁：電話、地圖、預約、表單步驟、片刻切換、照片探索工具列、外部連結。不做「標題上方一顆大圖示」的排版。
- 尺寸跟隨文字（1.1em），顏色跟隨 `currentColor`；「孩子的一天」時間軸的六個片刻以圖示取代序號，序號改由面板內的 01 / 06 承擔。摺疊指示（FAQ 與片刻問答）維持 ＋／− 字元。
- 新增圖示：到 Iconify 查 `ph:` 前綴的 Regular 版本，把 body 加進 sprite 的 `<symbol id="i-名稱">`。

## 首屏主視覺（2026-09-14 審查後定案）
審查結論：版型（左對齊、手繪底線、中文手動斷行）沒問題，問題出在「先把素材壓暗再放白字」的深色影片 hero 反射，使真實校園照失去日光與品牌色。以下為修正後的規則。

- **遮罩只保護文字，不蓋整個畫面。** `.studio-hero::before` 改為三條各自對應一個可讀性需求的帶：頁首帶（頂部 96px 實心、200px 內淡出）、底部說明列帶（250px）、左側文字欄帶（0–34% 實心，72% 歸零）。全部走 `rgb(var(--ink) / a)`，不再出現 `rgb(0 0 0 / a)` 或 `#fff` 字面值。孩子的臉所在的右側維持全日光。
- **數值依實測照片亮度決定，不憑感覺。** 桌面白字對 `assets/hero.webp` 的平均對比：導覽 5.78、eyebrow 4.65、預約鈕 5.01、副標 6.08，全部過 4.5:1。改動遮罩後必須重量，勿只憑肉眼。
- **手機不做滿版壓字。** 2.49:1 的橫幅照片放進 0.46:1 的手機首屏，孩子的白色制服正好落在文字位置，實測副標對比只有 2.66，加厚遮罩會把照片壓死。改為：照片佔上方 `clamp(180px,100% - 500px,46%)` 的帶（`object-position:82% center`），下緣淡入 `--deep`；文案、影片說明列、底部列全部落在深綠面板上，白字對比 13.8:1。照片因此從放大 1.46 倍變成縮小 0.6 倍，可見範圍從原圖寬度 19% 提升到 46%，臉不再被裁。
- **主要行動只有一個主色。** hero 主鈕 `background:var(--yellow);color:var(--deep)`（9.65:1），文案「預約來校園走走」明說是預約；頁首「預約參觀」維持白框幽靈鈕當重複入口。焦點環 `outline-offset:5px` 落在按鈕外的深色底上（13.97:1），不壓在黃色上。
- **品牌色在 hero 至少留一筆**：`慢慢長大` 的手繪底線 `stroke:var(--yellow)`。其餘文字維持白色。
- **一屏只留兩句**：h1 與副標。已刪除 `.hero-note`（原「給孩子，一個喜歡上學的理由。」）。底部左側改放校區資訊「五所校園：三民 · 左營 · 鳥松 · 仁武」，同時回應比較型家長；不再限制 `max-width:14ch`。
- **狀態文字不得超前畫面。** `#media-caption` 預設「義華校 · 生活影像」，只有在 `video` 的 `playing` 事件後才改成影片文案；減少動態、省流量、慢速連線與載入失敗時都維持海報文案。自動播放除 `saveData` 外也擋 `effectiveType` 為 2g／3g。
- **hero 高度必須收進一屏**：`.studio-hero-grid` 的 `padding-block` 改 `clamp(28px,5vh,56px)`。1280×800 與 1440×900 實測皆為單屏，暫停鈕不再落在摺線下。
- **素材規格（待園方提供）**：海報原圖至少 2400px 寬；另需一張直式校園照供手機使用；影片至少 1920×1080，並另備直式版。首屏影片現為園方廣告片剪出的 `assets/hero-campus.mp4`（見下方 2026-09-15 節）。
- **已移除的死碼**：`.paper-sun`、`.hero-sprout`、`.studio-hero-image figcaption`（DOM 中皆不存在）。`.seed-dot`（eyebrow 前的裝飾圓點）依「圖示只出現在動作旁」規則移除。
- **打包器**：`package_preview.py` 原本只內嵌 `styles.css`，會讓 `preview.html` 完全失去工作室主題；已修正為同時內嵌 `studio.css`。

## 首屏字型、按鈕與校園影片（2026-09-15 定案）
- **標語字型**：維持 LINE Seed TW ExtraBold 800；尺寸 `clamp(2.5rem,1.55rem + 3.6vw,4.6rem)`（1440px 時 73.6px）、行高 1.24、字距 .01em，陰影改為柔一點的 `0 2px 28px` 加 `0 1px 2px`。句尾標點（，。）以 `.punct{margin-inline-start:-.24em}` 收進來：子集字型雖列有 `halt`／`palt`，實測在 Chrome 無效（「，」「。」仍是 1em 全形），所以用負邊距而不是 OpenType 特性。手繪底線只畫在「慢慢長大」四字下，句號在底線外。
- **hero 的字型例外**：eyebrow、兩顆主按鈕、影片控制鈕改用 LINE Seed TW Bold 700（.8125–.9375rem，字距 .04–.18em），讓首屏是同一個聲音；其他頁面的按鈕與內文仍是系統字。用字全在 `chars-bd.txt` 子集內，沒有新增字型檔。
- **副標**：`clamp(1.0625rem,.95rem + .45vw,1.25rem)`、行高 1.85、`color-mix(in oklch,var(--white) 90%,transparent)`，比標語退一層。
- **按鈕**：兩顆同高 56px（手機 54px、直向堆疊滿寬），圓角維持 2px。主鈕黃底深綠字、日曆圖示放在文字前（gap 10px），`text-shadow:none`；次要行動「看看孩子的一天」由文字連結改為白框幽靈鈕，與頁首「預約參觀」同一語言。hover 只在 `(hover:hover)` 下上浮 2px 加陰影，active 回落；transition 走 ease-out-quint。
- **進場**：eyebrow → 標語 → 副標 → 按鈕依序上浮（.9s，間隔 120–160ms），底線在 .8s 後用 `stroke-dasharray` 畫出（1.1s）。所有基底樣式就是完成狀態，`prefers-reduced-motion` 時直接顯示，已實測（`animation:none` 下 opacity 1、dashoffset 0）。
- **影片**：`assets/hero-campus.mp4` 由園方廣告片剪出，`design/hero-video/build.sh` 可重剪：右上角校徽以 delogo 抹除、裁掉底部字幕帶成 1080×800、七個戶外鏡頭放慢 0.5× 並補幀、11.7 秒、2.5MB、無音軌。刻意不用 31.6–32.4 秒那顆（綠色 T 恤上的大字 VIETNAM 會搶過中文標語）。開頭是黃衣女孩的笑容（同時是海報幀 `hero-campus-still.webp`），結尾是另一個鏡頭，loop 接點只是一般剪接，不會在同一鏡頭內跳格。`object-position:50% 35%`（手機 `50% 40%`）。文案：海報「常春藤 · 校園生活影像」，`playing` 後「常春藤 · 校園生活影片」。
- **遮罩新增第四條帶**：右下角 `radial-gradient(60% 48% at 100% 100%,rgb(var(--ink) / .55) 0 30%,rgb(var(--ink) / 0))`，只服務影片說明列與控制鈕。離線以 12 幀試算（`design/hero-video/` 同一套遮罩模型）：說明列最差幀 3.59 → 6.66、控制鈕 4.08 → 8.11；臉部所在的中央區不受影響（2.82 → 2.84）。
- **對比實測（1440×900，遮罩後、12 幀最差值）**：標語 7.22、副標 6.86、eyebrow 7.68、幽靈鈕 5.83、導覽 6.37、說明列 6.66、控制鈕 8.14，全部過 4.5:1；海報幀更高（標語 11.9）。手機文案仍在深綠面板上，未變。
- **素材限制**：來源是 1080×1080 社群版廣告，字幕與浮水印都燒在畫面裡，桌面放大到 1440 寬後略軟。正式版請園方提供無字幕、無浮水印的 1920×1080 原始檔，改 `build.sh` 的鏡頭秒數重剪即可。

- 校區資料新增 `line`（字串或 `null`）、`facebook`、`fbNote` 三個欄位；`campusSocial()`／`campusPills()`／`campusMapFrame()` 三個共用函式分別產生卡片圖示、抽屜與內頁的大按鈕、地圖區塊。
