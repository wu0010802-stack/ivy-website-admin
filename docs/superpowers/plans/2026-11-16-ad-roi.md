# 廣告成效與成本＋各里結婚對數 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 招生統計新增「廣告成效」子分頁（各廣告平台的花費對照官網預約、到場、預繳），Google 花費從 GA4 自動抓、其他平台每月手填；官網進站時記下廣告平台；區域分析加上各里結婚對數。

**Architecture:** 官網 `ivy_src` cookie 的 touch 多一個平台代碼 `p`，送單時寫進 `visit_requests` 兩個新欄位。後端新增 GA4 Data API 讀取器（沿用 Search Console 的服務帳戶與快取）、手填花費表與 CRUD、`ad_roi.py` 純函式算成本；後台 `StatsTab` 多一個子分頁。結婚對數照出生（ODRP061）的 `Series` 機制新增 ODRP060 一組，接進 `trends.py` 與區域分析里表、出生走勢。

**Tech Stack:** Nuxt 4 shared TS（web/shared）、FastAPI 0.136.1 + SQLAlchemy 2.0 + Alembic、Vue 3 + Element Plus（admin）、Vitest、pytest、Playwright（tests/stack）。

**Spec:** `docs/specs/2026-11-16-ad-roi-design.md`（本計畫只做階段一：§5～§9）
