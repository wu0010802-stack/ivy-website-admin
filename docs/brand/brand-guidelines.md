# 常春藤官網品牌規範

2026-09-24 整理。內容全部取自已定案的紀錄（`PRODUCT.md`、`DESIGN.md`、`CLAUDE.md`），本檔不新增規則；兩邊有出入時，以 DESIGN.md 裡日期較新的定案為準，並回頭修正本檔。

適用範圍：公開官網 `web/`。後台 `admin/` 另有一套操作用色票，見第 8 節。凍結的 vanilla 原型（根目錄 `index.html`、`styles.css`、`studio.css`）不跟著改。

## 1. 品牌個性

- **大器、溫暖、親切。** 大器的版面框架，配上溫暖的品牌細節。
- **對象**：正在替孩子找幼兒園的高雄家長，多半用手機。
- **原則**：真實校園影像優先，沒有資料就不虛構；五校資訊要能清楚比較；大幅影像、充足留白、中文閱讀優先。
- **避免**：過度卡通化、過量裝飾、大量英文搶過中文、把其他學校的素材當成常春藤的。

## 2. 名稱與 Logo

- **全名**：常春藤教育機構／Ivy Educational Institution。五校：義華、明華、崇德、國際、仁武。
- **頁首字標**：彩色校徽＋中英兩行字標，左上角完整呈現。
  - 中文「常春藤教育機構」：Noto Sans TC 600，桌機 30px，Logo 綠 `#075B30`。
  - 英文「Ivy Educational Institution」：Source Sans 3 400，桌機 18px，Logo 藍 `#29266D`，與中文等寬、左右對齊。
  - 疊在首屏影片上時兩行都改白色；字標不加陰影。
  - 1100px 以下中文 24px；760／380／360px 以下 18／16／15px；英文維持中文的 60%。
- **分頁圖示（favicon）**：用頁首同一個彩色校徽，不含右側字標。
- **不要做**：
  - 用兩層濾鏡疊圖的方式替 Logo 去背（已否決）。
  - 30 週年標記：還沒拍板，不能順便上線。
  - 在 Logo 旁加上沒定案的標語或裝飾。

## 3. 色彩

**唯一來源：`web/app/assets/css/tokens.css`。** 樣式表和元件都不寫色碼，只引用變數；要透明度時用 RGB 三元組，例如 `rgb(var(--ink) / .6)`。

| 變數 | 約等於 | 用途 |

| `--yellow` | `#F8CF68` | 暖黃 |

| `--cream` | `#F5F2E5` | 奶油色區塊底 |

### 3.3 用色規則

- 綠色是品牌主色；金色只用在預約入口和重點標示，不當大面積背景。
- 遮罩、文字、錯誤、時間軸顏色一律走變數，不寫 rgba／oklch 字面值。
- 首屏遮罩的對比要對**實際照片像素**量，桌機和手機分開量；手機首屏不做滿版壓字。
- **新增顏色**：先確認現有變數真的不夠，再加進 `tokens.css` 對應的群組，並在 DESIGN.md 記錄定案。不要在元件裡直接寫色碼。
- **例外**：下列程式碼讀不到 CSS 變數，色碼只能寫在程式裡，改色時要一起改：
  - `app.vue` 的 `theme-color`（對應 `--paper`）
  - `utils/entranceCurtain.ts`：開場布幕的 3D 材質與燈光
  - `utils/entrance-policy.ts`：hydration 前的布幕底圖
  - `utils/paperPrints.ts`：拍立得 WebGL 讀不到 DOM 時的備用色

## 4. 字型

| 角色 | 字型 | 備註 |
|---|---|---|
| 標題 h1–h3 | LINE Seed TW Bold 700（首屏標語 ExtraBold 800） | **只有子集**，寫新標題前要先查缺字，缺字會退回 PingFang |
| 分校名、預約頁大標 | Ivy Campus Serif（Noto Serif TC 500） | 共用 `--fs-campus-name` |
| 品牌字標 | Noto Sans TC 600／Source Sans 3 400 | 各自獨立子集；「週年」另切一檔 |
| 英文小標、日期 | Source Sans 3 400 | 一律用 `--font-en` |
| 內文、表單、按鈕 | 系統字（PingFang TC、微軟正黑體） | |

- **字級只用 12 階**：`--fs-xs` 12、`sm` 14、`md` 16、`lg` 18、`xl` 20、`2xl` 24、`3xl` 28、`4xl` 32、`5xl` 40、`6xl` 48、`7xl` 60、`8xl` 64。例外（頁首、品牌字、校名、流體字級等）見 DESIGN.md「字體審查 B 批」。
- 中文說明文字最小 12px；只有裝飾性英文小標可以更小。
- 標點：h1–h3 行首開括號收半格；「，」「。」維持全形，不收。
- 補字流程在 `assets/fonts/README.md`：另切新檔，不動既有子集。

## 5. 圖示與符號

- 只用 **Phosphor Regular** 一套，尺寸跟隨文字（1.1em），顏色跟隨文字色。
- 圖示只放在動作旁邊：電話、地圖、預約、表單步驟、外部連結等；不做「標題上方一顆大圖示」。
- `↗` 只用在離開本站的連結。`→`／`←` 只用在有先後順序的操作，例如表單上一步／下一步。其他按鈕不加箭頭。

## 6. 文字與用語

- **中文優先。** 英文只留在品牌名、頁首導覽的英文副標（`lang="en"`）和外部連結。
- 小標用中文短語，名稱跟導覽一致。
- 示意用的內容（例如還沒填正式消息）必須標示「示意內容」，不能讓家長以為是真的。
- 社群連結：目前只有義華有 LINE／FB，其他四校留空待補，**不能拿義華的代填**。
- 預約用語依狀態區分：送出表單是「已收到需求」、時段待園方確認是「待確認」，只有園方確認後才叫「預約成立」。

## 7. 影像

- 用真實的校園照片和影片；沒有照片就留白或註明，不拿其他學校的素材。
- 五校線稿用各校專屬版本；首頁五校區塊的 hover 淡彩取自各校實景照片。
- 照片說明寫「圖片說明」，不寫「替代文字」這類工程用語。

## 8. 後台（`admin/`）

後台依 2026-09-22 定案，參考園務後台（ivy-frontend）：深藍灰側欄、青藍操作色、淺灰工作區。這套色票**刻意和官網品牌分開**，唯一來源是 `admin/src/style.css` 的 `:root`。

- 綠色只表示「已上線／成功」，暖黃表示「草稿／待注意」，側欄待處理數字也用暖黃。
- 疊在照片上的標記、圖說用 `--on-photo*`、`--photo-caption-*`。
- 對話框否定鈕統一寫「先不要」；畫面上不出現 eyebrow、樣板、版本號等工程用語。

## 9. 可及性底線

- 可點元素至少 44×44px。
- 支援「減少動態」：動畫在減少動態模式下要直接呈現最後狀態。
- 可以只用鍵盤操作，焦點框看得到。
- 文字放大到 200% 不會被裁切。
