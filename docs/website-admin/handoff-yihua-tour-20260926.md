# 義華校園探索：補場景的後台操作（2026-09-26）

明華、崇德、國際、仁武四校的校園探索，已經在程式裡換成舊官網的真實場景（`web/server/data/site-fixture.json`）。義華不一樣：正式站的義華校園探索存在後台（`campus_tour`），官網以後台為準，改程式不會生效。所以義華新的場景要在後台加。

舊官網 ivykids.tw「校園介紹」有六個空間。義華後台現在有三個場景（戶外廣場、綠色園藝、共創教室），分別對應大大廣場、綠色園藝、共創教室。還沒放的是花花世界、藝術走廊、可愛動物區。

## 操作步驟

1. 後台「素材庫」上傳下面兩張照片（舊官網原圖，比例剛好是校園探索要的 8:5，不必再裁）。
2. 後台「校園探索」選義華校，新增場景，照片從素材庫選剛上傳的那張，場景名稱、說明、熱點照下表填。熱點位置是百分比（X 0 最左、Y 0 最上）。
3. 存草稿、預覽確認熱點位置，再發布。
