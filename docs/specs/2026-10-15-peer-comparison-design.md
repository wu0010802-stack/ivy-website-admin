## 1. 背景與目標

區域分析的「附近幼兒園」只看得到類型、核定人數、kiang 推算的「月費（估）」與裁罰旗標；托嬰只有核定與實際收托。使用者 10-15 要「撈更多資料去比對」，目的選定為**附近同業比較**：本校在附近同業之中，價格與條件落在哪裡。給總部與分校訂價、說明、招生話術用，只在後台。

公開資料查證（§2）後選定範圍 B：幼兒園逐項收費落點、空間與服務欄位、托嬰月費／評鑑／準公共。查證時發現附近清單混著已停業的園所（kiang `is_active` 不會變回 0），同日另一案已經在修，本案依賴它（F3）。

### 1.1 成功標準

1. 區域分析多一個「附近同業收費」區塊：選年齡（2–5 歲），看本校一學期公告收費在半徑內**私立一般**園所裡的位置（中位數、範圍、排名、落點條、逐項對照）；準公共、公立、非營利只當背景。
2. 「附近幼兒園」清單列上顯示公告收費（取代「月費（估）」），展開看得到每位幼生室內／戶外面積、幼童專用車、兼辦國小課後與逐項收費。
3. 「附近托嬰」清單顯示月費、評鑑等級、準公共；摘要能對照本校 2 歲班月均。
4. 收費全量每 30 天、托嬰明細每 7 天自動更新（`WEBSITE_GEO_AUTO_SYNC` 開著時）；收費學年落後目前學年時，畫面明講。
5. 同業統計只算營業中的園所（由前置案保證）。
6. 家長資料不送任何外部服務；新端點只讀公開園所資料。

### 1.3 不做

- **家長實付試算**：F2。
- **現存名單修正**：前置案（F3）。
- **歷年收費、漲幅、半日班、上下學期分開**：F4。
- **實際就讀人數、填滿率**：全國只公開核定人數；教育部統計處的幼生數只到縣市層級（`edu_B_2_2_2.csv`），逐校查不到。
- **115 學年收費**：在驗證碼後面，不繞過（F6）。
- **評鑑結果、裁罰明細**：C 案。評鑑結果要自己爬教保資訊網（Railway 能否連上未測）；裁罰明細雖然公開，放進後台要另外核可。
- **托嬰的違反法令紀錄、負責人、退費說明**。
- **招生簡章 PDF 推估預計招收名額**：自由文字，約四成園所有上傳。
- **預測、替同業打分、地圖彈出框加收費、公開官網顯示**。
- **幼童專用車車輛數**：kiang 把車牌表存成空白字元，只能判斷有或無。

## 4. 同步

### 4.1 幼兒園四個新欄位（改 `parse_preschools`，在前置案改好的版本上加）

面積去掉「平方公尺」與千分位逗號轉成 float，不是有限正數就 NULL；`shuttle` 用**原始字串**判斷（不先 strip）：有任何字元＝有、空字串＝無、沒有這個鍵＝NULL；`is_after` 照 §3。`_apply` 原本就會把 `incoming` 的欄位覆寫到既有列，不用另外處理。同步日誌多印「有幼童專用車 N 所」。

### 4.2 幼兒園收費（新 `sync_kindergarten_fees`，模組 `geo/fees.py`）

- **時機**：同一輪背景同步裡，`sync_kindergartens` 結果是 `updated` 才接著做；`geo-sync`（CLI）同樣。幼兒園同步失敗或略過時不做，避免拿舊名單補收費。
- **判斷模式**：先照 F6 找最新學年 Y。三年都找不到 → `last_error`「找不到任何學年的收費檔」，結束。Y 比 `active_version` 新，或 `synced_at` 為空或距今 ≥ 30 天 → 全量；否則補缺。
- **抓檔**：每所 GET 一次，間隔 0.2 秒；404 視為未公布收費；其他 HTTP 錯誤、逾時、超過單檔上限、JSON 解析失敗都算網路錯誤（只計數、寫一筆 WARNING，不中斷整輪）。整輪超過 20 分鐘就中止，這一輪視為失敗（全量不換版；補缺已經抓到的照樣寫入）。
- **解析**（純函式 `parse_slip(data) -> list[FeeRow]`）：只讀 `slip`。對每個年齡 2–5：取 `上學期.class.全日班`，`全學期總收費.小計` 不是正整數時改取 `下學期`；仍然不是 → 該年齡不存。學期項目取 `小計`；`課後延托費` 取 `單價`（月）；數字用既有 `_int_or_none`（去逗號與空白）。`months` 取該學期的 `months`（不是 0.5 到 12 之間的數字就 NULL）。`交通費` 存 `單價` 去掉多餘空白、空字串為 NULL、截到 40 字。
- **寫入**：全量：在一個交易裡刪掉整表、寫入新的列、更新狀態，前提是通過 F9 門檻；補缺：只 insert（同一所同一年齡已存在就略過）。兩種模式都更新 `checked_at`、清掉 `last_error`；全量另外更新 `active_version`、`label`、`synced_at`。
- 不做檔案匯入：來源和名單同一台主機，連不到時名單也會失敗。

### 4.3 托嬰明細（改 `sync_babycare`）

名單 `apply_babycare` commit 之後，逐一抓營業中各所的明細檔（間隔 0.2 秒，整輪 5 分鐘）。解析（純函式 `parse_babycare_detail(data)`）：

- `收費情形.日間托育` 裡 `費用名稱` 去空白後等於「托育費」的第一筆：`費用金額` → `monthly_fee`（正整數才收）、`費用說明` → `fee_note`（去頭尾空白、連續空白收成一個、截到 200 字）。
- `評鑑等級` 去空白，空字串為 NULL，超過 8 字視為格式錯誤、存 NULL。
- `最近一次評鑑年度` 是 2–3 位數字才收。
- `準公共資格`：「是」→ true、「否」→ false，其他 NULL。

成功的那一所逐筆更新五個欄位；失敗的保留舊值。超過 5 分鐘就停，還沒抓的保留舊值，下一輪再抓。這一段失敗不改 `babycare` 的同步結果（名單已經成功），只寫 WARNING 日誌與計數。`--babycare-file` 匯入名單時不抓明細。

## 5. 計算（`app/admissions/peer_fees.py`，只讀）

`query_peer_fees(db, campus_key, *, radius_km, age, today)`：

1. 本校座標與 `locate_error` 沿用 `area.py` 的取法；沒定位就回 `campus.locate_error`，其他欄位空。
2. 半徑內營業中園所沿用 `kindergartens.nearby`；`is_own` 判斷同 `query_kindergartens`（任一校 50 公尺內）。
3. 本校園所：F12。沒有 → `own_missing: "not_found"`；有但沒有這個年齡的收費列 → `"no_fee"`。
4. 每一所 left join `geo_kindergarten_fees`（`age` 相符）。
5. 四種類型各自：半徑內家數（不含本機構）、有收費家數、中位數／最低／最高（F14）。私立一般另算本校排名。
6. 逐項（學費、雜費、材料、活動、午餐、點心、延托（月））：本校金額、私立一般有該項金額的家數與中位數（家數少於 3 就不算）。
7. 月均＝學期總收費 ÷ 月數，四捨五入到元；月數為 NULL 就不算。

`query_babycare` 的 summary 加：半徑內有月費的家數、中位數、最低、最高（家數少於 3 不算中位數）；`own_age2_monthly`＝本校 2 歲的月均（沒有就 null）；`fee_school_year`＝收費學年。

## 12. 風險與限制

- **收費停在 114 學年**：115 學年要過驗證碼，kiang 的爬蟲寫死 114（去年 7/17 才改年）。kiang 一更新，F6 會自動全量換新；在那之前畫面照 F18 寫明。kiang 停更，資料會一直停在 114 學年。
- **檔名對應**：園所改名後，要等 kiang 依新名稱產生收費檔才對得回來；這段期間該所顯示「未公布收費」。
- **幼童專用車靠空白字元判斷**：kiang 若改成存空字串，會全部變成「無」；測試釘住現行格式，同步日誌記「有幼童專用車 N 所」，數字掉到 0 時看得到。
- **公告收費不等於實收**：園所可能另有優惠、才藝費、註冊費攤提方式不同；項目歸類也不一致，畫面已註明。
- **依賴前置案**：前置案沒上 main 之前，同業統計會混進停業園所；所以本案不在它之前上線。
- **與「在籍學生」並行**：兩邊都會改 `AreaTab.vue`、同步、migration；合併時解衝突並重接 `down_revision`。
- **實作時的決定（2026-10-16）**：
  - 收費與托嬰明細在「從沒匯入過」時不等名單到期（上線第一輪就有資料，不必 `--force`；`--force` 會連門牌一起重抓）。托嬰明細在名單沒更新的輪次只補還沒有明細的那幾所。
  - 群組範圍欄位叫 `lowest`／`highest`（§6 範例寫 `min`／`max`）。
  - 同業分組（私立一般／準公共）用**收費學年**的準公共期間判斷，不用目前學年：收費是 114 學年的公告，就用 114 學年的類型分組（真實資料有 2 所 115 學年才轉準公共）。附近幼兒園清單的類型仍是目前學年。
  - 找到的收費學年比使用中的舊時整輪不換版（和門牌的月份倒退護欄同一個道理）；`--force` 不略過 F9 的兩道門檻與這道護欄，人工放行見 `deploy/README.md`。
  - 收費與托嬰明細的同步都有硬性逾時；托嬰明細這一段任何失敗只寫 WARNING，不中斷後面的資料種類。
  - 收費從沒匯入過時，附近幼兒園列尾寫「—」，匯入過但這所沒公布才寫「未公布收費」。
  - 匯出 CSV 的檔名帶年齡（「附近同業收費-3 歲」）。
